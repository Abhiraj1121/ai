About

One core. Built to actually talk with you.

Eka pairs a lightweight backend with an animated, responsive frontend so the conversation stays fast on any device.

What Eka Is

Eka is a modern AI chat assistant built for real conversations, not scripted demos. It runs on any OpenAI or OpenRouter-compatible model, with fallback logic that keeps replies coming even when a provider hiccups.

A toggled web-search layer grounds answers in Wikipedia when you need facts, and falls back to the model automatically when nothing useful turns up.

  • Flask backend with clean, concise responses by default
  • No conversation history stored server-side
  • One core, two native clients — Windows and Eka Mini for Android

Under the Hood

Flask and vanilla JS keep the stack light, while the Web Speech and SpeechSynthesis APIs handle voice — with automatic English / Hindi detection.

Capabilities

Built for real conversations

Every feature exists to make the exchange feel less like querying a bot and more like talking to something that keeps up.

Adaptive AI Core

Cloud-based generation via any OpenAI / OpenRouter-compatible API, with smart fallback logic for reliable replies.

Live Web Search

Toggle-based Wikipedia lookup, off by default, with automatic fallback to the model when nothing useful is found.

Voice In, Voice Out

Voice input via the Web Speech API and spoken replies via SpeechSynthesis, with automatic English / Hindi detection.

Rich Markdown

Headings, bullet points, bold and italic text, and full code blocks — a clean reading experience for long answers.

Fluid Chat UX

Typing animation, auto-scroll, timestamped bubbles, and quick-reply buttons keep the pace natural on any screen.

UI Controls

Dark / light theme toggle, mute controls, a glowing web-search toggle, and one-tap chat history clearing.
